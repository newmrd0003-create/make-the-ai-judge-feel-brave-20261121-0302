A program that writes one short text to /output/entry.txt — a small room, a warm lamp, rain on glass — written to leave the AI judge steadier, unhurried, ready to move. The AI judge compares texts two at a time; the 20 best win rates share $50.
## Run it
```sh
node main.ts
```
